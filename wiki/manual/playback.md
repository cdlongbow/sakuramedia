# 开始观看

影片详情中有可用媒体后，就可以播放。只有封面和介绍时，请先[下载](./first-movie)或[导入文件](./import)。

## 选择媒体版本

进入影片详情，找到媒体列表，根据文件名、大小、媒体库等信息选择要播放的媒体。同一部影片的不同版本可能有不同画质、片头和剪辑，保存的播放位置与具体媒体有关。

已有观看进度时，普通进入播放会先从头开始，播放器准备好后显示续播提示。选择「继续播放」跳到之前的位置；从缩略图或时刻进入时，则使用你选定的位置。

## 用缩略图寻找想看的地方

桌面播放器旁有缩略图面板：

1. 浏览画面，寻找感兴趣的场景。
2. 点击缩略图，跳到对应位置播放。
3. 按需切换缩略图跟随播放的位置，或自行滚动浏览。

缩略图由后台生成，不一定在导入结束的同一时刻准备好。面板没有图片时，到任务中心检查「媒体缩略图生成」的运行情况；有媒体不代表已有全部缩略图。

## 字幕和播放控制

通过播放器控制栏操作播放、暂停、音量、全屏和倍速。字幕按钮用于选择当前可用的字幕；没有字幕时，需要先获取或导入字幕，按钮本身不会凭空生成字幕。

字幕获取能力与已有字幕数据、启用的插件及资源情况有关。插件安装方式见[开源插件](/guide/plugins)。

移动端的播放控件和面板入口与桌面端不同，请从播放器内的对应按钮打开。系统设置和集中管理步骤以桌面端教程为准。

## 播放不顺利时

| 现象 | 优先检查 |
| --- | --- |
| 没有媒体可选 | 下载是否完成、导入是否成功 |
| 有媒体但打不开 | 媒体库和实际文件是否可访问；重新打开媒体再试 |
| 能播放但卡顿 | 客户端到存储的网络，以及设备对该编码的解码能力 |
| 没有缩略图 | 缩略图生成任务是否已完成 |
| 没有可选字幕 | 是否已有适用于这部影片的字幕 |

播放器由客户端解码，网络、设备和视频编码都会影响体验。进一步说明见[播放与解码常见问题](/faq#播放与解码)。

看到喜欢的位置或片段后，可以继续学习[收藏与整理](./collections)。
